# Rev-A Circuit Review Images

This directory contains one current, accepted schematic screenshot for each
reviewed Rev-A circuit block.

Use the block ID followed by a short lower-case description:

```text
PC01-operating-mode-and-3v3-rail.png
PC02-target-5v-switch-and-two-range-monitor.png
RC01-routing-fabric.png
TB03-i2c-functional-device.png
```

Replace an image under the same name when a material circuit change is
reviewed. Git retains the earlier image. Do not retain every intermediate
layout screenshot.

Each image should show the circuit title, references, values, pin numbers, net
labels, support components and complete circuit boundary at a readable scale.
These images are visual review evidence; the KiCad schematic and verified
connectivity remain authoritative.
