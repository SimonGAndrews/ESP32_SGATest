This is the experimental IDF5 consolidation discussed in #2758.

It contains the source diff generated by the spec-driven Python transformer:

source corrections in this commit.

Wired V1 harness and wider functional testing is still to follow.

question is whether it has retained the correct IDF5/shared code and removed
only the obsolete IDF3/IDF4 branches.

It is not intended to be merged as-is and does not propose the final board
names, CI changes or repository structure. Old IDF3/IDF4 build jobs may fail
because the legacy build infrastructure is deliberately still present.
