# Hardware Reference Outputs

This directory holds published hardware reference outputs that are useful
outside KiCad itself, such as exported schematic PDFs.

Live KiCad project files remain under `KICAD/`.

## ESP32-C3 Harness

```text
ESP32_C3/schematic-v1-0.pdf
ESP32_C3/schematic-v1-1.pdf
```

`schematic-v1-1.pdf` is the current ESP32-C3 harness schematic reference.

```text
ESP32_V1/schematic-v1-0.pdf
```
